# BurgerBash

A landing page for a made-up burger restaurant. I built it to practise page layout, a menu made from data in JavaScript, and form checking.

## Sections

- Hero
- Menu with tabs (Burgers, Sides, Drinks). The items come from `js/menu-data.js`
- Weekly offers
- Our story
- Opening hours and a table booking form

## How to run

Open `index.html` in a browser, or use Live Server in VS Code.

## Change the menu

Open `js/menu-data.js`, copy one line, change the name, price and picture, and save.

## Images

Pictures go in `images/` (see the image guide for file names). If one is missing, the page still works.

The restaurant, address and phone number are made up. The booking form only checks the fields and sends nothing.

Built with HTML5, CSS3 and vanilla JavaScript.
